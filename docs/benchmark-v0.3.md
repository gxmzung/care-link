# v0.3 합성 데이터 비교 실험

## 목적
동일한 합성 방문 6건과 의료진 2명을 대상으로 **단순 ID순 라운드로빈 배정**과 **OR-Tools VRPTW** 결과를 비교합니다.

## 실행
```bash
python -m app.benchmark
python -m pytest -q
```

## 해석 기준
- `baseline`: 시간 제약을 무시할 수 있는 단순 배정 비교군. 위반 건수 반드시 함께 표기
- `optimized`: 방문 가능 시간·근무시간 제약을 고려하는 최적화
- `comparison_valid=false`이면 이동시간 감소율을 **성과로 계산하거나 제시하지 않습니다**.
- 이 비교는 동일한 의료진·방문 데이터의 알고리즘 비교이지 기관 현장 실증이 아닙니다.
- 실제 도로·이동시간, 응급성, 업무 숙련도, 현장 일정 변경 등은 반영되지 않았습니다.

## PPT 문구
> CARE-LINK 연구용 MVP는 합성 방문 6건과 의료진 2명을 대상으로 방문시간 제약을 고려한 일정 생성 및 배정 결과 검증을 구현하였다. 실제 기관 적용 효과는 미검증이다.

검증 결과를 캡처할 때는 GitHub Actions 실행 기록과 합성 데이터 표시를 함께 넣으세요.
