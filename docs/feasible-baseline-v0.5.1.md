# v0.5.1 공정한 기준 일정 보완

기존 ID순 라운드로빈 기준 일정은 시간 제약 위반이 10개 시나리오 모두에서 발생했습니다. 이동시간만 비교하면 잘못된 결론을 낼 수 있습니다.

새 기준은 방문 마감시간 순으로 처리하면서 방문 가능시간·의료진 근무 종료를 만족하는 의료진 중 가장 빨리 완료할 수 있는 사람을 선택하는 **독립적인 탐욕 휴리스틱**입니다.

- 기준 일정도 시간 제약 위반을 허용하지 않음
- 기준 일정이 모든 방문을 배정하지 못하면 이동시간 개선률 비교에서 제외
- 시나리오별 `baseline_assigned`와 `optimized_assigned`를 함께 보고
- 비교 가능 시나리오가 0개라면 이동시간 개선률을 주장하지 않음
- 탐욕 기준이 최선의 대안이라는 뜻은 아니며 실제 운영 절차와도 다름

실행: `python -m pytest -q`, `python -m app.scenario_benchmark`
