# PPT 13·14페이지 개발 증빙 가이드

## 실행
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
브라우저에서 `http://127.0.0.1:8000/demo`에 접속합니다.

## 13페이지
- 제목: 방문의료 일정·동선 운영지원 시제품 구현
- 화면: `/demo`의 의료진별 일정 및 배정 결과
- 캡션: 합성 방문 6건·의료진 2명 대상 연구용 시뮬레이션 화면

## 14페이지
- 제목: 제약조건 기반 최적화 검증
- 왼쪽: 기준 일정과 OR-Tools 일정의 배정 건수·이동시간·제약 위반 비교
- 오른쪽: GitHub Actions 자동 테스트 및 재현 가능한 JSON 결과
- 주의: 기준 일정이 제약 위반 시 이동시간 감소율을 개선 성과로 표현하지 않음

## 필수 고지
- 기관 실제 환자·의료진·도로 이동시간을 사용하지 않았음
- 민들레 기관 공식 시스템 또는 실제 도입 결과가 아님
- 의료 안전성·운영 비용 절감 효과는 현장 실증 전 미검증
