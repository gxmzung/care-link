# v0.5 다중 시나리오 합성 검증

## 실행
```bash
python -m pytest -q
python -m app.scenario_benchmark > scenarios.json
```

## 설계
- 난수 시드 0~9, 각 시드당 방문 8건, 의료진 2명
- ID순 라운드로빈 기준 일정과 OR-Tools 일정의 방문시간·근무시간 제약 검사
- 양쪽 모두 전건 배정 및 시간 제약 위반 0건인 시나리오만 이동시간 개선률 계산
- 비교 가능 시나리오 비율과 비교 불가능 시나리오 수를 반드시 함께 보고
- 결과가 없을 경우 개선률은 null이며 임의 숫자를 채우지 않음

## 해석
합성 평면 좌표 기반이며 도로망, 방문 우선순위, 의료진 전문성, 환자 개인정보, 현장 변동은 미반영. 실제 운영 개선 효과를 입증하지 않습니다.
